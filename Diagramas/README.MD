# 📊 Diagramas do Projeto Clickdesk

Esta pasta centraliza toda a documentação visual e modelagem do sistema **Clickdesk**. Os diagramas aqui presentes seguem os padrões UML (Unified Modeling Language) e são essenciais para o entendimento da arquitetura, fluxo de dados e regras de negócio do projeto.

---

Diagramas exportados em **PNG** em cada pasta de sprint e em [`DIAGRAMAS FONTE/`](./DIAGRAMAS%20FONTE/README.md). O arquivo `Completo.asta` é opcional.

### 🛠 Ferramentas Utilizadas

* **Lucidchart** e/ou **Astah** (ou equivalente UML): modelagem conforme as sprints do PIM; a equipe define qual usa — nenhuma é obrigatória por si só.
